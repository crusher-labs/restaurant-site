# AGENTS.md - restaurant-site

`restaurant-site` is a one-off crusher-labs site experiment: a static restaurant landing page.

Workspace rules: `x:\crusher-labs\AGENTS.md`. Global rules: `~/.claude/CLAUDE.md`. This file only adds what is specific to this repo.

## Status

**Parked since 2026-10-19** (founder's call in the control review): no host, no active work, nothing scheduled. Redesigned on 2026-08-09/10 as "Hearth"; some descriptions below were written before that redesign, so check the code before trusting them.

## What it is

- **Stack:** Vite 4 + React 18 SPA (JSX, no TypeScript), client-side routing via React Router 6, styling with Tailwind CSS 3 + Radix UI primitives, animation via Framer Motion, icons via lucide-react. `@/` aliases `./src`.
- **Purpose:** Marketing/landing site for a fictional fine-dining venue ("Saint-Laurent Restaurant"). Two routes: `/` (Hero, About, Menu preview, Reservation, Contact) and `/menu`. Generated by Hostinger Horizons, then scaffolded into the crusher-labs org as a template (the single commit is "create template").
- **Hosting:** None wired up. No Vercel/Netlify config, no GitHub Pages workflow, no `CNAME`. It builds to a static `dist/` (gitignored); deploy target is undecided. Treat it as a build-only static experiment until a host is added.

## Conventions

- The `build` script prefixes `node tools/generate-llms.js || true`, but `tools/` does not exist; the `|| true` swallows the failure so `vite build` still runs. The llms-generator step is a no-op today; do not assume it produces anything.
- Leftover boilerplate identity: `package.json` name is `web-app`, `README.md` says `workouts-generator`, and `index.html` `<title>` is "Hostinger Horizons". These are scaffold artifacts, not the real product name (which is "Saint-Laurent Restaurant"). Fix them if you make this a real site; don't treat them as authoritative.
- There are two `AboutSection.jsx` files (`src/AboutSection.jsx` and `src/components/AboutSection.jsx`). The app imports the one under `src/components/`; the root-level copy is unused.

## What NOT to do

- **Branches: `dev` is the working branch and `main` is fast-forward only.** Both exist and were equal on 2026-10-19. Never commit to `main` directly, docs included; this workspace lets you merge `dev` into `main` yourself once the gate is green.
- **No `Co-Authored-By` or AI-attribution trailers** in commits or PRs. User identity only.
- **Do not put secrets in tracked files.** `.env*` is gitignored; keep credentials out of the repo.
- Do not commit `dist/` or `node_modules/` (both gitignored).
